# 路线A：UI 自动化规格说明（VJ1000喷码机管理系统RT1.1 Pro）

本文档固化与现场确认的关键信息，作为后续实现与联调的依据。

---

## 一、窗口与主要控件
- 窗口标题：`VJ1000喷码机管理系统RT1.1 Pro(A)`（以实际为准）
- 关键按钮/区域：
  - 左下绿色：`载入信息`（系统“打开文件”对话框，支持粘贴完整路径并回车）
  - 左侧“插入元素”面板：
    - 绿色输入框：用于键盘录入“架次号”，为标准文本框，位置固定
    - `插入文字` 按钮：在点阵画布的点击位置铺开文本
  - 右侧：
    - 黄色：`更多功能`
    - 蓝色：`自动发送信息`（保持关闭）
    - 红色：`传输信息`（执行下发）
  - 中下：`实时监控` 文本区（发送状态、串口信息）

---

## 二、业务数据与规则
- OCR 产出：`图号+架次号`（示例：`ABC.123.D.555.123`）
- 目标喷印：`功能+图号+架次号`（拼接在设备端用已有字体渲染）
- 字符文件：文本位图（逐列，16 高 × W 宽，末尾 0 列为空白）。示例：`resources/J11B.5324.B.655.971`
- 约束：
  - 架次号字符集：[A-Z0-9]，自动转大写；最大长度 6；不含符号
  - 首行格式：`.../16/.../...` 中 16 为固定高度；异常格式暂不兼容

---

## 三、动作序列（一次发送）
1) 置前主窗口。
2) 点击 `载入信息` → 在系统打开对话框粘贴“字符文件绝对路径”并回车。
3) 在“插入元素”绿色输入框录入本次架次号（与上次相同则跳过）。
4) 计算插入位置：
   - 从字符文件读取：
     - total_cols = 总列数；
     - blank_start_col = 从哪一列起为全 0；
     - top_row = 末段有效内容的最小行索引（0..15）。
   - 横向滚动：p = blank_start_col / total_cols。
     - 优先用 UIA ScrollPattern.SetScrollPercent(水平, p×100%)；
     - 不支持则拖动横向滚动条滑块至轨道左端 + p×轨道宽度（导入后滚动条可见）。
   - 纵向定位：cell_h = 画布高/16，click_y = canvas_top + (top_row + y_offset)×cell_h；
     - y_offset 默认 0，可配置微调以兼顾美观。
   - 横向点击位置：优先在“画布右侧安全区”（如 canvas_right - x_margin）点击，或按目标列换算 click_x。
5) 在画布点击确定插入锚点 → 点击 `插入文字` 按钮。
6) 点击 `传输信息` 按钮。
7) 判定成功：先用“实时监控 3 秒内有新增文本”判成功；后续替换为真实关键字匹配。
8) 失败重试：
   - 第一次失败：重新滚动到空白区 → 再次点击画布 → `插入文字` → `传输信息`；
   - 仍失败：再次 `载入信息` 回到原始版面后重试一次；
   - 连续失败 2 次：提示人工。

---

## 四、坐标与控件边界
- 读取画布控件矩形用于：
  - 将行/列索引换算为屏幕点击坐标（适配不同分辨率/DPI）；
  - 计算 cell_h 与 click_y；
  - 若支持，读取滚动条轨道矩形以进行百分比拖动。
- 画布蓝色点颜色：约 RGB(56,113,223)。仅用于辅助手段（兜底视觉确认空白区），主流程不依赖颜色。

---

## 五、缓存策略（按文件）
- 键：字符文件绝对路径 + (size, mtime) 签名。
- 值：
  - scroll_percent（p）、x_offset_safe、y_offset、top_row
  - last_ok_ts（最近一次成功）
- 说明：每个文件单独缓存一份；与文件夹无强关系。

---

## 六、文件索引与选择
- 仅需一个“根目录”；允许按产品分子文件夹。
- 查找规则：
  - 优先用完整路径；找不到则在根目录递归搜索“图号.*”取最优候选；
  - 记忆“最近成功的路径”，下次优先。

---

## 七、成功/失败判据（临时版）
- 成功：`实时监控` 文本 3 秒内有新增行；
- 失败：3 秒无新增，或监控文本包含“错误|失败|未连接|端口占用”。
- 后续：待现场提供真实“成功关键字”，收紧匹配规则。

---

## 八、异常与回退
- 插入位置不理想：再次点击 `载入信息` 回到原始版面后重试。
- 滚动条不可见：说明未导入或内容很短；此时无需滚动直接点击右侧安全区插入。
- UI 失焦：强制置前窗口后重试；必要时坐标点击升级为控件定位 + 坐标混合。

---

## 九、运行与环境建议
- 串口由厂家软件独占；本程序不直接打开 COM。
- Windows 缩放 100%，避免坐标漂移；保持前台会话，避免 RDP 控制生产机。
- 记录日志与截图：保存“载入→滚动→点击→插入→传输→监控”的关键步骤与耗时。
