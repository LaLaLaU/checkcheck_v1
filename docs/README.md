# 文档总览

本目录整合了项目说明与历史文档，统一术语为“图号/架次号”，并移除“标牌与导管比对”的旧描述。

- 快速开始与使用：请见项目根目录 `README.md`
- 项目简介（精简）：`INTRODUCTION-check.md`
- 部署与打包：`setup_steps.md`、`delivery_offline/README_DELIVERY.txt`

扩展文档（本目录）：
- 技术栈与目录结构：`TECH_STACK.md`
- 产品需求（PRD）：`PRD.md`
- 实施计划（Plan）：`Implementation_Plan.md`
- 已知问题：`ISSUES.md`
- 更新日志：`CHANGELOG.md`

术语约定：
- 图号（原 MAIN）：例如 A12.3456.B.123.123
- 架次号（原 HEAD）：例如 AB123
