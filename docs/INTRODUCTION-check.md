# 项目简介（精简版）

CheckCheck 是一款用于识别“图号”和“架次号”的小工具。当前版本仅做识别，不包含“标牌与导管”的比对逻辑。

## 能力概览
- 选择图片或使用摄像头进行识别
- 自动提取“图号”和“架次号”
- 历史记录保存（可选）

## 术语与规则
- 图号（原 MAIN）示例：A12.3456.B.123.123
- 架次号（原 HEAD）示例：AB123
- 核心规则：
  - 图号-严格：`^[A-Z][A-Z0-9]{2,4}\.[0-9]{4}\.[A-Z]\.[0-9]{3}\.[0-9]{3}$`
  - 图号-宽松：`^[A-Z0-9]+(\.[A-Z0-9]+){2,4}$`
  - 架次号：`^[A-Z]{1,3}\d{2,4}$`

更多使用与安装请参见 README.md。
