# CheckCheck 图号/架次号识别

一个专注识别“图号”和“架次号”的小工具。当前版本仅做识别，不做“标牌与导管”的比对，界面更简单、启动更快。

## 术语说明
- 图号：原代码中的 MAIN（示例：A12.3456.B.123.123）
- 架次号：原代码中的 HEAD（示例：AB123）

## 快速开始（在线安装）
1) 环境准备：Windows 10/11，Python 3.8+
2) 安装依赖：`pip install -r requirements.txt`
3) 启动程序：`python src/main.py`

提示：
- 推荐使用统一启动脚本 `start.bat`（优先离线包，其次 conda 环境，最后系统 Python）。
- 也可使用 `start_with_conda.bat` 在名为 `checkcheck` 的 conda 环境中运行。

## 使用说明
- 选择图片识别：点击“上传图片”，选择图片后，点击“开始识别”或按 Enter
- 摄像头识别（可选）：相机可用时，保持取景，点击“开始识别”
- 拖拽上传（可选）：将图片拖入主界面指定区域
- 结果显示：在“识别结果”区域显示“图号、架次号”

## 识别规则（核心）
- 图号-严格：`^[A-Z][A-Z0-9]{2,4}\.[0-9]{4}\.[A-Z]\.[0-9]{3}\.[0-9]{3}$`
- 图号-宽松：`^[A-Z0-9]+(\.[A-Z0-9]+){2,4}$`
- 架次号：`^[A-Z]{1,3}\d{2,4}$`

说明：程序会优先按规则提取候选文本。若格式不完全符合，可放宽规则或进行人工确认。

## 常见问题
- 首次运行时间较长：OCR 引擎初始化需要时间，耐心等待即可。
- 缺少运行库：若提示缺少 VC++ 组件，请安装 “Microsoft Visual C++ 2015-2022 Redistributable (x64)”。
- Windows N 版本：如无法播放/打开多媒体相关能力，安装 “Media Feature Pack”。
- CPU 指令集：建议 CPU 支持 AVX/AVX2；过旧 CPU 可能无法运行。
- 模型目录：如未提供本地模型，程序会回落到 PaddleOCR 默认模型（联网环境更佳）。

## 版本说明
