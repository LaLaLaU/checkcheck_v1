# CheckCheck 标牌图号识别与复制工具

CheckCheck 是一个基于计算机视觉与 OCR 的标牌文字识别工具，聚焦于从金属标牌上识别“图号”，并将识别结果自动复制到系统剪贴板，便于在喷码设备中直接粘贴输入。系统同时识别“架次号”，提供“一键复制架次号”的按钮（不自动复制）。

## 项目概述

系统通过工业相机或上传图片的方式捕获金属标牌，利用 OCR 技术识别得到“图号/架次号”。系统会：
- 自动复制图号到剪贴板
- 提供“复制架次号”按钮以手动复制

## 功能特点（当前版本）

- 支持图片上传与相机实时识别
- 自动检测文本区域与识别
- 图号自动复制到剪贴板（去掉尾点，仅允许大写与英文点号）
- 架次号识别并提供“复制架次号”按钮（手动复制）
- 历史记录（可选保存识别截图与图号）

## 安装与使用

### 环境要求

- Python 3.8+
- Windows 10/11操作系统

### 安装步骤

1. 克隆或下载项目代码
2. 安装依赖库：
   ```
   pip install -r requirements.txt
   ```
3. 运行程序（推荐使用批处理脚本确保在 conda 环境中运行）：
   ```
   start_with_conda.bat
   ```

## 使用说明（关键流程）
- 选择“上传图像”或“启动相机”并点击“开始识别”
- 识别完成后：
  - 图号会自动复制到剪贴板（状态栏会提示“已复制”）
  - 若识别到架次号，“复制架次号”按钮会变为可点击，点击即可复制

## 规则说明
- 合法字符：仅大写字母 A-Z、数字 0-9、英文点号 '.'
- 图号优先匹配严格格式：`^[A-Z]{3,8}\.\d{3,8}\.[A-Z]\.\d{3,8}$`；若失败，再用宽松格式兜底：`^[A-Z0-9]+(\.[A-Z0-9]+){2,4}$`
- 架次号格式：`^[A-Z]{1,3}\d{2,4}$`
- 图号无尾点：若识别结果末尾包含点号，会被自动去除
