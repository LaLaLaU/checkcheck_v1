## CheckCheck - 产品需求文档 (PRD)

- 版本：2.0
- 日期：2025-08-31
- 目标：仅识别标牌“图号”，自动复制；识别“架次号”提供手动复制；不进行文本比对。

### 1. 产品概述
应用通过相机实时捕获标牌图像，使用 OCR 识别图号并自动复制到剪贴板；如识别到架次号，提供按钮手动复制。提供识别结果图预览、状态颜色提示、历史记录多选删除及文件同步删除。

### 2. 目标用户
- 生产线质检与操作人员

### 3. 系统架构与技术
- Python 3.8+ / PyQt5 / OpenCV / PaddleOCR（PaddlePaddle 3.0.0，PaddleOCR 2.10.0）
- SQLite 本地历史库
- QThread 相机线程；QSoundEffect 提示音
- 取消 Difflib/文本比对

### 4. 功能需求
- 相机：
  - 实时预览，完整显示，不裁剪、不拉伸
  - 单次识别与实时识别模式
- 识别：
  - 自动抽取 MAIN（图号）与 HEAD（架次号）
  - MAIN 符合严格或兜底规则
  - MAIN 自动复制；HEAD 提供按钮复制
- 结果呈现：
  - 结果区左侧文本、右侧识别结果图预览
  - 识别结果图绘制绿色框（MAIN 加粗），左上角 ASCII 标签（MAIN/HEAD/TIME）
  - 状态颜色：绿=严格；黄=兜底；红=无匹配/错误
- 历史记录：
  - 支持多选删除
  - 可选“仅删记录”或“删记录+文件”
- 快捷操作：
  - Enter/小键盘 Enter、鼠标中键触发“开始识别”
- 已移除：
  - 上传图片、切换到图片、设置页、比较逻辑

### 5. 文本规则
- HEAD：`^[A-Z]{1,3}\d{2,4}$`
- MAIN（严格）：`^[A-Z][A-Z0-9]{2,4}\.[0-9]{4}\.[A-Z]\.[0-9]{3}\.[0-9]{3}$`
- MAIN（兜底）：`^[A-Z0-9]+(\.[A-Z0-9]+){2,4}$`
- 处理：大写化、移除空格、移除尾点、仅允许 A-Z/0-9/“.”

### 6. 非功能需求
- 单次识别时延 ≤ 1s（典型）
- 连续实时识别稳定运行 ≥ 8 小时（待长测）
- 首次提示音已预热，确保首次即播放

### 7. UI 概览
- 上：相机预览（自适应完整显示）
- 下：左文本（架次号在上、图号在下，含“复制架次号”）+ 右预览图
- 边距：结果区左右留白，分隔条隐藏
- 默认窗口尺寸：最小 1024×1152，分区约 7:3

### 8. 交付与部署
- 提供 conda-pack 环境包与启动脚本
- 离线电脑解压即可运行
