## CheckCheck 标牌图号识别与复制工具

CheckCheck 是一个基于 OCR 的标牌文字识别工具，专注从标牌上识别“图号”（MAIN）并自动复制到剪贴板；若识别到“架次号”（HEAD），提供按钮手动复制。系统不进行“标牌文字 vs 喷码文字”的比对。

### 功能特点
- 相机实时预览（不裁剪、不拉伸，等比例完整显示）
- 单次识别与实时识别两种模式
- 图号自动复制到剪贴板
- 架次号识别后可一键复制（不自动复制）
- 识别结果图预览（在结果区右侧显示标注图）
- 状态提示颜色：绿色=严格匹配；黄色=宽松匹配；红色=未识别/无效
- 快捷操作：Enter 和鼠标中键触发“开始识别”
- 历史记录：支持多选删除；可选仅删记录或同时删除本地图片文件
- 成功识别提示音（首次播放已预热修复）

### 识别与校验规则
- 仅允许字符集：A-Z、0-9、英文点号“.”
- 自动转换为大写，移除空格，移除尾部点号
- 架次号 HEAD 正则：`^[A-Z]{1,3}\d{2,4}$`
- 图号 MAIN 正则（优先严格，其次兜底）：
  - 严格：`^[A-Z][A-Z0-9]{2,4}\.[0-9]{4}\.[A-Z]\.[0-9]{3}\.[0-9]{3}$`
  - 兜底：`^[A-Z0-9]+(\.[A-Z0-9]+){2,4}$`

### 使用说明
1) 双击 `start_with_conda.bat` 启动应用
2) 选择模式：
   - 单次识别：按下 Enter/鼠标中键执行一次识别
   - 实时识别：勾选实时识别复选框，系统自动连续识别
3) 结果：
   - 图号：自动复制到剪贴板，并显示在结果区
   - 架次号：若识别到，可点击“复制架次号”
   - 右侧显示识别结果图（绿色框，MAIN框加粗；左上角 ASCII 标签：MAIN/HEAD/TIME）
   - 状态颜色指示当前识别有效性
4) 历史记录：
   - 支持多选删除
   - 可选择“仅删除记录”或“删除记录并删除本地图片文件”

### 界面说明
- 上部：相机画面（自适应比例完整显示）
- 下部：左侧文本结果（架次号在上，图号在下，含“复制架次号”按钮），右侧识别结果图预览
- 已移除：上传图像、切换到图片、设置

### 环境与启动
- 推荐环境：Windows 10/11，Python 3.8+（通过批处理在 conda 环境中启动）
- 启动：双击 `start_with_conda.bat`

### 离线交付（概览）
- 使用 conda-pack 打包环境（详见 `setup_steps.md`）
- 将应用目录 + 打包环境拷贝至离线电脑，解压后执行 `start_with_conda.bat`
